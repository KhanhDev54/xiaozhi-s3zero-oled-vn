5 Sửa lỗi thiết bị

        

          Nạp sai firmware, mạch treo, không nhận cổng COM
          
Mạch có nút BOOT (ESP32-S3 Zero, mạch 2.8"):

          
    
            
  1. Rút cáp. Giữ nút BOOT, cắm cáp vào máy tính (hoặc bấm RESET), rồi thả BOOT.
    2. 
            
  2. Bấm Kết nối ở trên, chọn cổng COM vừa xuất hiện.
    3. 
            
  3. Bật ô Xoá toàn bộ flash trước khi nạp rồi nạp lại firmware đúng loại mạch.
    4. 
          

        

        

          Cổng COM chập chờn, mạch khởi động lại liên tục (không có nút BOOT)
          
Dùng phần mềm chính hãng Flash Download Tool của Espressif trên Windows:

          
    
            
  1. Tải về tại trang
              công cụ của Espressif
              rồi giải nén.
    2. 
            
  2. Mở flash_download_tool_x.x.x.exe, chọn ChipType ESP32-S3, WorkMode Develop, LoadMode UART.
    3. 
            
  3. Tick dòng đầu, chọn file firmware .bin (tải ở mục 1), địa chỉ 0x0; phần SPI để mặc định.
    4. 
            
  4. Cắm mạch, chọn đúng cổng COM (cổng đang chập chờn), BAUD 921600 (cáp kém thì 115200).
    5. 
            
  5. Bấm START liên tục đến khi ô trạng thái báo SYNC, chờ tới FINISH.
    6. 
          

        

        

          Không thấy cổng COM nào
          
    
            
  • Dùng cáp USB có truyền dữ liệu (cáp chỉ sạc sẽ không hiện cổng).
    • 
            
  • Cắm thẳng vào máy tính, tránh hub USB.
    • 
            
  • Mạch dùng chip chuyển USB (CH340/CP210x) thì cài driver của hãng chip đó.
    • 
          

        

      

    


    

      
Hướng dẫn nhanh

      
    
        
  1. Cắm mạch vào máy tính bằng cáp USB-C có truyền dữ liệu.
    2. 
        
  2. Bấm Kết nối, chọn cổng COM của mạch. Nếu không thấy cổng: giữ nút BOOT, bấm RESET, thả BOOT rồi thử lại.
    3. 
        
  3. Chọn firmware trong danh sách (hoặc kéo thả file merged-binary.bin), địa chỉ 0x0.
    4. 
        
  4. Bấm Bắt đầu nạp. Xong thì mạch tự khởi động lại; nếu màn hình đen, bấm RESET.
    5. 
        
  5. Lần đầu: điện thoại kết nối Wi-Fi Xiaozhi-xxxx để cài mạng cho mạch.
    6.
